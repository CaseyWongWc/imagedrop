# ImageDrop V2 - Full Specification

**Author**: Casey + Dan (DanAI)  
**Date**: February 5, 2026  
**Purpose**: AI-powered lecture capture with live transcription, photo annotation, and multi-AI team access

---

## Problem Statement

Current ImageDrop works but has limitations:
- OneNote discontinued - HTML exports getting confusing
- Photos embedded as base64 (huge file sizes)
- No cloud storage for AI team access (Echo, Dan, Comet, Gemini)
- No OCR/text extraction from photos
- Camera UI issues on mobile
- No AI annotations or summaries
- Manual organization only

---

## Core Features

### 1. Live Capture System
| Feature | Description |
|---------|-------------|
| Live Transcript | Records every ~30 seconds, displays in real-time |
| Photo Capture | Camera button + device upload option |
| Auto-Checkpoint | If no photo taken for X minutes, auto-save checkpoint |
| End Recording | Only ends after final transcript chunk completes |

### 2. AI Annotation System
| Feature | Description |
|---------|-------------|
| Per-Photo Analysis | OpenAI Vision analyzes each photo (whiteboard, slides, diagrams) |
| Markdown Annotations | AI generates notes between each photo/checkpoint |
| Context Window | Uses: previous AI annotations + lecture materials uploaded |
| Gap Filling | If gap exists between annotations, AI fills in context |
| Regenerate | Any annotation can be regenerated on demand |

### 3. Demo Generation
| Feature | Description |
|---------|-------------|
| Python Demos | AI creates runnable code demos for concepts |
| Scratchpad | Editable area to tweak and run demos |
| One-Click Generate | Button next to annotation: "Generate Demo" |
| Language Options | Python preferred, but configurable |

### 4. UI/UX
| Feature | Description |
|---------|-------------|
| Font Size Control | Adjustable text size |
| Photo Scale Control | Adjustable image display size |
| Side Panel Layout | `[Transcript/Photo] -> [AI Summary] -> [Demo Button]` |
| Temp Paste Pad | Quick copy area for sending to Perplexity/Echo |
| Migrate Button | Move temp content into main notes |
| Ctrl+F Search | Search across all content |
| Folders and Titles | Organize by class/date |

### 5. Storage and Export
| Feature | Description |
|---------|-------------|
| Cloud Storage | All photos stored with shareable public URLs |
| Google Drive Integration | Sync notebooks to Drive folder |
| Google Docs Export | Replace HTML with Docs (photo links, not base64) |
| Photo Links | Each photo gets permanent URL instead of embedding |
| Multi-AI Access | Echo, Dan, Comet, Gemini can all access notes via links |

## Technical Architecture

### Stack Recommendation
```
Frontend: React or vanilla JS (mobile-first)
Backend: Flask or Node.js
Database: PostgreSQL (Replit built-in) for metadata
Storage: Google Drive API or Replit Object Storage for photos
AI: OpenAI API (GPT-4 Vision for photos, GPT-4 for annotations)
Export: Google Docs API
```

### Data Model
```
Notebook
  - id
  - title
  - class_name (CS4800, CS2520, etc.)
  - created_at
  - updated_at
  - items[]
      - id
      - type (transcript | photo | checkpoint | annotation)
      - timestamp
      - content (text for transcript, URL for photo)
      - ai_annotation (markdown)
      - demo_code (python)
      - order
```

### API Endpoints
```
POST /notebook/new - Create notebook
POST /notebook/:id/transcript - Add transcript chunk
POST /notebook/:id/photo - Upload photo, get URL back
POST /notebook/:id/checkpoint - Force checkpoint
POST /notebook/:id/annotate - Generate AI annotation
POST /notebook/:id/demo - Generate demo code
GET /notebook/:id/export/docs - Export to Google Docs
GET /photo/:id - Public photo URL
```
